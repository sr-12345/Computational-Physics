# Computational Physics Project

An assortment of numerical and computational methods for use in computational physics contexts.

# Content

Numerical Derivatives:
- Demonstrates the forward difference method for numerically differentiating a continuous function.

Numerical Integration:
- Uses Simpson's rule to numerically integrate a continuous function.

Differential Equations 1:
- Simulates the nuclear decay of Carbon-14 to demonstrate the Euler and Runge-Kutta 4 methods of numerical integration.

Differential Equations 2:
- Simulates the trajectory of a cannon ball experiencing a drag force to apply the Euler method in a new context.

Monte-Carlo Methods:
- Simulates a system of nuclei which can undergo decay from one state to another spontaneously, based off some probability
